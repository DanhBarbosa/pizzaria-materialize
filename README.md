# Pizzaria Materialize

Aplicação web desenvolvida utilizando HTML, CSS, JavaScript e Materialize CSS para simular o gerenciamento e apresentação de uma pizzaria.

## Status

✅ Projeto concluído

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Materialize CSS
- LocalStorage

## Funcionalidades

- Página inicial
- Cadastro de informações
- Cardápio da pizzaria
- Localização
- Dashboard com estatísticas
- Armazenamento de dados em LocalStorage

## Estrutura do Projeto

```text
Imagens/
assets/js/
index.html
login.html
cardapio.html
localizacao.html
```

## Como Executar

1. Clone o repositório
2. Abra o arquivo `index.html`
3. Navegue pela aplicação utilizando o navegador
